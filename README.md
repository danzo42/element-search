# コマツ エレメント検索（PWA）

P.ELE 2026 建機エレメント総合カタログ「KOMATSU コマツ」P.1〜30 を元にした、スマホ用のエレメント品番検索アプリです。
ホーム画面に追加でき、一度開けばオフラインでも使えます。

**公開URL：https://danzo42.github.io/peacock-element/**
（GitHub の `main` ブランチに push すると、`public/` が GitHub Pages に自動で公開されます）

## フォルダ構成

| パス | 内容 |
|---|---|
| `public/` | 公開するアプリ本体（このフォルダをそのままWebサーバーに置く） |
| `data-src/p01.tsv`〜`p30.tsv` | カタログ1ページ＝1ファイルの元データ（タブ区切り） |
| `tools/build-data.ps1` | 元データから `public/data.js` と確認用CSVを作る |
| `tools/make-icons.ps1` | アプリアイコンを作る |
| `tools/serve.ps1` | パソコンでの動作確認用サーバー（http://localhost:8080/） |
| `コマツ_エレメント一覧.csv` | 全データ（Excelで開ける） |
| `要確認一覧.csv` | 原本で淡色・かすれ・綴じ目欠けがあり、原本確認が必要な行 |

## 元データ（TSV）の列

`ページ / 機種区分 / 型式 / エンジン / シリアル / オイル / エア / 燃料 / 作動油 / 備考`

- 原本の「〃」はそのまま `〃` で入力しています。ビルド時に直前行の値に置き換わり、アプリ上に「原本〃」と表示されます。
- 備考に「確認・判読・欠け・不確実・検証中」を含む行は、アプリ上で「要確認」と表示されます。

## データを直したとき

1. `data-src/pXX.tsv` を編集
2. PowerShell で `tools/build-data.ps1` を実行
3. `public/sw.js` の `VERSION` の数字を1つ上げる（スマホ側のキャッシュが入れ替わります）
4. commit して GitHub に push（数分で公開URLに反映）

## スマホのホーム画面に入れるには

公開URLをスマホで開いたら：

- **iPhone（Safari）**：共有ボタン →「ホーム画面に追加」
- **Android（Chrome）**：画面上部の「インストール」ボタン、またはメニュー →「アプリをインストール」
