# エレメント検索アプリ（PWA）

P.ELE 2026 建機エレメント総合カタログ（ピーコックエレメント）の、スマホ用の型式・品番検索アプリです。
ホーム画面に追加でき、一度開けばオフラインでも使えます。

**公開URL：https://danzo42.github.io/element-search/**
（GitHub の `main` ブランチに push すると、`public/` が GitHub Pages に自動で公開されます）

## 収録状況

| メーカー | カタログのページ | 状態 |
|---|---|---|
| コマツ | P.1〜30 | 収録済み（読み取りルール適用前のため全て「未確認」） |
| CAT | P.31〜55 | 収録済み（P.51〜55は2回読み済み＝「確認済み」、P.31〜50は「未確認」） |
| 日立 | P.56〜75 | **読み取り中**（P.56〜58のみ収録。残りは順次追加） |

アプリの画面では、2回読みが済んでいない行に「未確認」の印と左端の色帯が付きます。
原本で読み取れなかった箇所は `???` と表示され、品番としては検索されません。

## フォルダ構成

| パス | 内容 |
|---|---|
| `public/` | 公開するアプリ本体 |
| `data-src/<メーカー>/pXX.tsv` | カタログ1ページ＝1ファイルの元データ（タブ区切り）。`komatsu` / `cat` / `hitachi` |
| `data-src/makers.json` | メーカーの定義（表示する列と列名） |
| `data-src/checked.json` | 2回読みが済んだページの一覧（これに載ったページが「確認済み」になる） |
| `tools/build-data.ps1` | 元データから `public/data.js` と確認用CSVを作る |
| `tools/serve.ps1` | パソコンでの動作確認用サーバー（http://localhost:8765/） |
| `エレメント一覧.csv` | 全データ（Excelで開ける） |
| `要確認一覧.csv` | 原本で薄い・かすれ・欠けがあり確認が必要な行（`???` を含む行を含む） |
| `目視確認用サンプル.csv` | 各メーカーからランダムに選んだ25行。原本のページと照らして目視確認するための表 |

## 元データ（TSV）の列

先頭の9列は共通です。

`ページ / 機種区分 / 型式 / エンジン / シリアル / オイル / エア / 燃料 / 作動油`

その後ろは、メーカーによって異なります。

| メーカー | 9列目以降 |
|---|---|
| コマツ | `備考` |
| CAT | `ステアリング(ST) / TM・パイロット(P) / 備考` |
| 日立 | `サクション / ドレン・パイロット / 備考` |

- 原本の「〃」は `〃` のまま入力します。ビルド時に直前行の値に置き換わり、アプリ上に「原本〃」と表示されます。
- 読み取れなかった箇所は `???` を入れ、理由を備考に書きます。
- 原本で薄く印字された純正番号は `[ ]` で囲みます（アプリ上では点線枠で表示）。

## データを追加・修正したとき

1. `data-src/<メーカー>/pXX.tsv` を編集（新メーカーは `makers.json` に定義を追加し、フォルダを作る）
2. 2回読みを済ませたページは `data-src/checked.json` に追記
3. PowerShell で `tools/build-data.ps1` を実行
4. `public/sw.js` の `VERSION` の数字を1つ上げる（スマホ側のキャッシュが入れ替わります）
5. commit して GitHub に push（数分で公開URLに反映）

## スマホのホーム画面に入れるには

公開URLをスマホで開いたら：

- **iPhone（Safari）**：共有ボタン →「ホーム画面に追加」
- **Android（Chrome）**：画面上部の「インストール」ボタン、またはメニュー →「アプリをインストール」
